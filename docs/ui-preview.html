备选方向

B · 社团海报

桃绯粉 + 薄荷青，冲击力强，适合短视频封面；但大面积粉色容易像美妆/电商，正文易疲劳。

C · 学术夜校

长春花蓝 + 可可棕，安静复古，适合讲座；但社团招新类活动会显得不够热闹。
