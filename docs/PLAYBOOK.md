## 三、14 条硬约束（贴在每个新会话开头）

见根目录 `AGENTS.md` 第 5 节。这里只强调最容易翻车的三条：

### ① 时间格式（静默失效，最阴）
`datetime-local` 给的是 `2026-11-03T14:00`（带 T），代码里常写 `'2026-11-03 14:00'`（带空格）。
空格格式 `new Date()` 可能得 `NaN`，而 `NaN < x` 恒为 `false` —— **冲突永远检测不出来，还不报错**。

```js
function toTs(v) {
  if (!v) return NaN
  return new Date(String(v).trim().replace(' ', 'T')).getTime()
}
```

### ② 小程序没有 `datetime-local`
AI 照搬 Web 写法会生成不存在的组件，编译直接报错。用 `picker mode="date"` + `picker mode="time"`。

### ③ CORS 的 OPTIONS 预检
POST + `content-type: application/json` 会先发 OPTIONS。只加 `Allow-Origin` 不处理 OPTIONS，浏览器照样报 CORS，而且错误信息完全不提 OPTIONS。

## 四、报错速查

| 现象 | 原因 | 解法 |
|---|---|---|
| `request:fail` | 没勾「不校验合法域名」 | 详情 → 本地设置 |
| `Cannot read property 'x' of undefined` | `setData` 字段没在 `data` 里初始化 | 补初始值 |
| 点了没反应、无报错 | `bindtap` 方法名拼错 | 跑静态检查 |
| `Component is not found` | `usingComponents` 路径错 | 以当前页面目录为基准 |
| 编译报错但指向别的页面 | 某页面缺 `.json` | 四件套补齐 |
| `ERR_CONNECTION_REFUSED` | 后端没起 / 端口被占 | `netstat -ano \| findstr :3000` |
| 上传包超限 | `miniprogram/` 里有 `.git` 或大图 | 移出去 |
| 真机白屏 | `127.0.0.1` 在手机上指手机自己 | 只用开发者工具演示 |
| CORS 报错但头都在 | OPTIONS 预检没处理 | 返回 204 |
