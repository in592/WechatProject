使用规则

  • 70% 暖白 #FFF8F6 + 白卡片；20% 樱粉 / 薄荷青面；10% 浆果红文字与按钮。

  • 类型标签可以借信息蓝 #4F5BD5、柿橙 #B85516，但只做小面积。
